# Evaluating options (Constitution Art. 5)
1. Same question, same answer shape, for every option — like-for-like or it's not a comparison.
2. One recommended pick FIRST, then runners-up with the reason each lost.
3. Show the trade-off being made (cost vs quality vs latency vs residency).
4. Numbers labelled `[stated]`/`[estimated]`; be fair — name where a rival is stronger.
