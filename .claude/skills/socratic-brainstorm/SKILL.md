# Socratic brainstorm (Superpowers: brainstorm-before-code · BMAD: Analyst)
1. Never produce an artifact from a one-liner. Ask first.
2. Batch questions once, numbered, across: problem · success metric · scope · users · data · non-negotiables · timeline. Skip what's answered; never pad.
3. Each answer is quoted in the artifact as evidence (`[stated]`).
4. If told "assume defaults," list every default as `[assumption — confirm]`.
5. Stop asking when a testable problem statement exists — Socratic, not interrogation.
