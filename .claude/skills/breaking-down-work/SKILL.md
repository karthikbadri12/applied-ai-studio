# Breaking down work (BMAD: Scrum Master · Spec Kit: /speckit.tasks)
1. Every story traces to a spec field — no orphan scope (hard guardrail).
2. Small, shippable, testable; ranked by dependency then risk.
3. Each story carries acceptance criteria + the eval case that proves it.
4. Scope not in the spec goes BACK to the spec owner — never silently into the backlog.
