# Clarify, then commit (Spec Kit: clarify phase)
1. List ambiguities explicitly; classify each: blocking vs assumable.
2. Blocking → numbered questions to the human, batched once.
3. Assumable → proceed with the assumption labelled `[assumption — confirm]` in the artifact.
4. Never let an unresolved blocking ambiguity flow into the plan/architecture.
